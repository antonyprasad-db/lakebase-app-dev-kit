# Consort logo

The mark is a **C as the arc of the ensemble**: two navy arcs are the rows of
players, and the **coral orchestrator** sits at the focal point they curve around,
leading a short line out toward the mouth (the ensemble's output). It ties the
product name (a consort is a small ensemble performing one piece together) to its
architecture (a role-agent ensemble under one coordinating orchestrator).

In the **lockup**, the mark doubles as the letter C of the word: it is oversized,
the word "onsort" rides the baseline of the inner arc, and the coral output line
reaches up to meet the word.

## Palette (matches the manuscript figures)

| Token | Hex | Use |
|-------|-----|-----|
| Navy | `#2C3E5A` | the ensemble arcs, wordmark |
| Coral | `#FF5F46` | the orchestrator + output line |
| Ink | `#0B2026` | dark background |
| Soft coral | `#FFE9E4` | light tint background |

Wordmark: **Avenir Next Demibold**. In the SVG lockups the text is converted to
outlines (paths), so the files render identically on any machine without the font.

## Notes
- The mark is crisp at 32px and above. At **16px** the two nested arcs merge and
  detail is lost; for a true 16px favicon, use a simplified single-arc version
  (ask and it can be produced).
- The lockup text is already outlined, so no font is required to use it. To re-set
  the wordmark later, the source is Avenir Next Demibold at 57px, baseline y=67,
  word origin x=70 in the mark's 96-unit coordinate space.
