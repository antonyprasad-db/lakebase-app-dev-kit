# Feature Proposals

Candidate features for this sprint, projected deterministically from the recorded feature-requests (the headless stand-in for the Spec Author's live proposal turn).

## F1-stock-visibility

**One-line ask:** Record and view stock by SKU and location

**Rationale:** I need the team to file a SKU's stock at a physical location and see it again. This is the foundation: until we can record what is on a shelf and read it back, nothing else in the warehouse works.

**E2E story:** Yes.
