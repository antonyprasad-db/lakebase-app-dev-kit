# S2: View home stock table

As a warehouse operator
I want to see all stock in a scannable table on the home screen
So that I can quickly check what is available at each location

## Details

The home screen displays:
- A table with columns: SKU, Location, Quantity (right-aligned for easy scanning)
- All stock records currently in the system
- An explicit "No stock at this location" message when viewing a location that has no records, never a blank page or empty area

The table is calm, readable, and suitable for quick scanning during warehouse operations.
