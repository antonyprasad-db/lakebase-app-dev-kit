# S2-view-home-stock-table

As a warehouse operator, I want to see stock by location on the home screen as a calm, scannable table, so that I can quickly find what quantities are stored where.

## Scope

- Display all stock records (SKU, location, quantity) in a table.
- Right-align quantity columns for easy scanning.
- Show an explicit "No stock at this location" state when stock is empty.
- Home screen is the landing page after login.
