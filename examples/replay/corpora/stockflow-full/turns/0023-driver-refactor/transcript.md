1. ✅ **Boundary no longer imports repository** – removed `import app.repositories.stock as stock_repo`
2. ✅ **Service owns its own repository** – added `from app import repositories as repos` at module level in service

4. ✅ **Service parameter renamed** – changed `_repo`/`_db` to clean public params (`db`)

The layering is now correct:
- **Boundary** (`app/routes/stock.py`) → imports only **service**
- **Service** (`app/services/stock.py`) → imports only **repository** (as a module-level dependency)
- **Repository** (`app/repositories/stock.py`) → imports only **models** and ORM

This fixes the dependency violation flagged in the review where the boundary was importing the repository, skipping the service's responsibility for owning its collaborators.
