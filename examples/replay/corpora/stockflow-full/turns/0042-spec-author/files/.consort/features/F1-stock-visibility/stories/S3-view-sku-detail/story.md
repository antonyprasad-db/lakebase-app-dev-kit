# S3-view-sku-detail

As a warehouse operator, I want to view a SKU's stock across all its locations, including its tracking code, so that I can see the complete inventory picture for one SKU and identify units by their combined tracking code.

## Scope

- Navigate to a detail page for a selected SKU.
- Display all locations where that SKU holds stock.
- Show the combined tracking code for each location.
- Display par level (optional detail); show "not tracked" clearly when not available.
- No par level editing in this story (read-only).
